# Как собрать код для «Переноса»

Код, который принимает поле «Загрузить из кода» в разделе «⇄ Перенос», — это **base64 от JSON-состояния** в кодировке UTF-8. Собрать его можно вручную, скриптом или попросить ИИ. Ниже — формат и готовый промпт.

## Формат состояния (JSON)

```json
{
  "v": 1,
  "dayinfo":  { "Пн": "описание дня", "Вт": "...", "Ср": "...", "Чт": "...", "Пт": "..." },
  "sched":    { "Пн": [ { "id": "theory", "start": "07:00", "end": "09:00" } ] },
  "blocks":   { "cXXXX": { "type": "rest", "label": "Медитация", "purpose": "..." } },
  "blocktext":{ "theory": { "label": "...", "tagline": "...", "purpose": "..." } }
}
```

Все секции необязательны — можно прислать только нужную. Как применяется при загрузке:

- `dayinfo` — описания дней; **мержится** (обновляет указанные дни, остальные не трогает).
- `blocks` — свои блоки; мержится.
- `blocktext` — правки описаний встроенных блоков (глобально); мержется.
- `sched` — расписание по дням; **заменяет** указанные дни.

Дни: `Пн Вт Ср Чт Пт Сб Вс`. Описание дня одно на день; чтобы задать разные темы теории по дням недели — используй `dayinfo` (по дням), а не `blocktext` (он глобальный, один на все дни).

## Минимальный пример — только темы дней

```json
{"v":1,"dayinfo":{"Пн":"Теория: роль PM","Ср":"Теория: JTBD","Пт":"Теория: гипотезы"}}
```

## Как закодировать

**Python:**
```python
import json, base64
payload = {"v":1,"dayinfo":{"Пн":"Теория: роль PM","Ср":"Теория: JTBD","Пт":"Теория: гипотезы"}}
print(base64.b64encode(json.dumps(payload, ensure_ascii=False, separators=(",",":")).encode("utf-8")).decode())
```

**JS (консоль браузера):**
```js
btoa(unescape(encodeURIComponent(JSON.stringify(payload))))
```

Оба дают один и тот же код. **Не считай base64 вручную** — для кириллицы легко ошибиться.

## Готовый промпт для ИИ

> Мне нужен код для импорта в офлайн-планировщик учёбы (функция «Перенос между устройствами»). Код — это base64 от JSON-состояния в UTF-8.
>
> Собери JSON вида:
> `{"v":1,"dayinfo":{"Пн":"...","Вт":"...","Ср":"...","Чт":"...","Пт":"..."}}`
>
> Мои темы на неделю:
> - Пн: <тема>
> - Вт: <тема>
> - Ср: <тема>
> - Чт: <тема>
> - Пт: <тема>
>
> Закодируй, **выполнив код** (не считай base64 вручную):
> `base64.b64encode(json.dumps(payload, ensure_ascii=False, separators=(",",":")).encode("utf-8")).decode()`
>
> Верни ТОЛЬКО итоговую строку-код, без пояснений.

Если у ИИ нет исполнения кода — попроси выдать Python-скрипт и запусти сам. Строку base64, «написанную» моделью на глаз, использовать нельзя: она почти наверняка будет битой.

## Как загрузить

Дашборд → **⇄ Перенос** → поле «Загрузить из кода» → вставь код → «Загрузить из кода». Загрузка заменит только те данные, что есть в коде.
