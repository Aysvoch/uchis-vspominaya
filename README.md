# Учись, вспоминая

**Система самообучения, построенная вокруг одного принципа: мозг усваивает не когда ты читаешь, а когда вспоминаешь.**

Открытый метод плюс офлайн-инструмент для тех, кто учится сам - смена профессии, подготовка к роли, глубокое освоение темы. В репозитории: интерактивный дашборд режима, методика и готовая колода карточек.

---

## Зачем это

Типичная ошибка самоучки - мерить учёбу часами: чем больше просидел, тем лучше. На деле:

- Глубокой концентрации у мозга **4-6 часов в день**, дальше идёт имитация учёбы.
- Перечитывание создаёт **иллюзию знания** - материал узнаётся, но не вспоминается.
- Усвоение даёт **вспоминание и применение**, а не количество прочитанного.

Вывод, вокруг которого собран весь метод: считать не часы за текстом, а **долю того, что смог вспомнить сам, без подсказки.**

---

## Метод в одном экране

**Три правила**

1. **4-6 часов** глубокой учёбы - потолок в день. Остальное лёгкое: язык, повторение, быт.
2. **Блоки 50/10** - 50 минут фокуса, 10 минут прочь от экрана.
3. **Каждый день - вспоминание.** Что не вспомнил без подсказки - и есть непройденное.

**День - три разных блока:** теория (впитываешь) → проект (производишь артефакт) → кейсы (тренируешь мышление), плюс обязательный прогон карточек.

**Метрика:** доля вспомненного сама растёт от повтора к повтору - значит учишься.

Полная методика: [`docs/method.md`](docs/method.md).

## Что в репозитории

```
.
├── docs/
│   ├── index.html   # интерактивный дашборд режима (офлайн, один файл)
│   └── method.md    # методика целиком
├── anki/
│   └── pm-interview-cards.txt   # колода из 13 карточек-принципов (пример наполнения)
├── README.md
└── LICENSE
```

**Дашборд** (`docs/index.html`) - самодостаточный HTML: открой в браузере, интернет не нужен, шрифты вшиты. Главный экран короткий, детали спрятаны внутрь: тап по дню открывает его часы, тап по блоку - разбор (для чего он, как пользоваться, примеры).

**Колода** (`anki/pm-interview-cards.txt`) - 13 карточек-принципов из разбора продуктовых кейсов (локализация метрики, ICE/RICE, RAT, работа с возражением по цене, «плательщик vs пользователь» и др.). Приложена как пример, чем наполнять систему.

## Как пользоваться

**Офлайн, сразу:** скачай репозиторий и открой `docs/index.html` в браузере.

**Онлайн (GitHub Pages):** Settings → Pages → Source: `main`, папка `/docs`. Через минуту дашборд будет доступен по адресу `https://<твой-ник>.github.io/<репозиторий>/`.

**Карточки:** в десктопном Anki - File → Import → выбери `pm-interview-cards.txt` (разделитель - табуляция, тип заметки «Базовый»), затем синхронизируй с телефоном.

## Как адаптировать под себя

Дашборд заполнен под пример - самообучение на продакт-менеджмент. Метод от домена не зависит: форкни и подставь своё.

- **Блоки** (`теория / проект / кейсы`) - под свою область. Суть сохраняется: впитываешь → производишь → тренируешь мышление.
- **Времена и дни** в дашборде - шаблон, а не предписание. Подстрой под свой ритм.
- **Колода** - замени карточки-принципы на свои: одна карточка - одна мысль, лицо формулируй как вопрос.

Расписание - это леса, а не рельсы: система работает на дистанции, пропущенный день ничего не рушит.
